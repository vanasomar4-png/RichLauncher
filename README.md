# RichLauncher

Мощный, быстрый и кастомный лаунчер для Minecraft на движке Electron.

**Официальный сайт:** [https://richlauncher.site.je](https://richlauncher.site.je)

## Возможности

- Удобное управление модами, текстур-паками и шейдерами
- Современный интерфейс
- Быстрый запуск клиентов
- Собственный дизайн

## Системные требования

- **ОС:** Windows 10 / 11
- **Процессор:** Intel Core i5-3470 / i5-3570 или лучше
- **Оперативная память:** от 2 GB
- **Видеокарта:** с поддержкой OpenGL
- **Место на диске:** 2–5 GB
